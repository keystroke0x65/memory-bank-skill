# Design notes

The skill's research basis stays inside the skill, because `SKILL.md` links to it:

- [`skill/memory-bank/references/research-basis.md`](../skill/memory-bank/references/research-basis.md)
  lists the papers the design draws on, maps each rule to its source and how it
  was adapted, and records known gaps and upgrade paths: embedding retrieval,
  a storage backend other than markdown, benchmark evals, and test-linked
  success signals.

The format and operations contract is
[`skill/memory-bank/references/spec.md`](../skill/memory-bank/references/spec.md).

Put design notes that aren't needed while the skill runs in this folder.
